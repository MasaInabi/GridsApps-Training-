
# Day 08 - Bootstrap Final Website

## Overview
A responsive 10-page software company website built for the Grids Apps Full Stack Development Internship.

## Pages
- Home
- About
- Services
- Solutions
- Projects
- Pricing
- Dashboard
- Blog
- FAQ
- Contact

## Technologies
- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript

## Features
- Premium dark and orange design
- Responsive layouts
- Offcanvas navigation
- Contact form validation
- Bootstrap modal
- FAQ accordion
- Dashboard filtering and CSV export
- Downloadable project brief

## How to Run
1. Open the Day08-Bootstrap folder in VS Code.
2. Open index.html using Live Server.
3. Navigate between the pages.
4. Test the interactive components.

## Notes
Dashboard data is illustrative. The contact form generates a project brief rather than sending a message to a server.
