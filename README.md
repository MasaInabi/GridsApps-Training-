
# Company Website

## Grids Apps Full Stack Web Development Internship

This project is a responsive multi-page company website built using HTML5 and CSS3.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Pages

1. Home - index.html
2. Profile - profile.html
3. About - about.html
4. Services - services.html
5. Blog - blog.html
6. Contact - contact.html
7. Registration - registration.html
8. Dashboard - dashboard.html
9. FAQ - faq.html
10. Pricing - pricing.html

## Features

- Responsive navigation
- Mobile-first layouts
- Responsive service cards
- Dashboard with sidebar and topbar
- Contact and registration forms
- FAQ section
- Black and orange design
- Keyboard focus styles

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in a web browser.
4. Use the navigation links to explore the website.

## Responsive Design

The website uses CSS Flexbox, Grid, and media queries to support mobile, tablet, and desktop screen sizes.
